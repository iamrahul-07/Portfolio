# 🌐 Portfolio – Rahul Vishwakarma

A modern, responsive **portfolio website** built with **React (Vite)** and **TailwindCSS**.
It showcases my **skills, projects, and contact details**, featuring smooth animations, dynamic typing effects, and an email contact form.

---

## 📌 Features

- ✨ Responsive design (mobile-friendly)
- 🎨 Built with **React + TailwindCSS**
- ⌨️ **Typewriter effect** on the homepage
- 🖼 Smooth animations with **Framer Motion**
- 📂 Sections: Home, About, Skills, Projects, Contact
- 📧 Contact form powered by **EmailJS**
- 📑 Resume download option
- 🌍 Social media integration

---

## 🛠 Tech Stack

- **Frontend:** React 19, Vite, TailwindCSS
- **Animations:** Framer Motion, React Simple Typewriter
- **Icons:** React Icons, Font Awesome
- **Email Service:** EmailJS
